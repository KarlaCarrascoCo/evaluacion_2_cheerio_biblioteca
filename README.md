# Evaluación 2 — Backend Biblioteca con Cheerio

## Descripción

Proyecto backend desarrollado con Node.js, Express y Cheerio.

El sistema procesa un archivo HTML de catálogo de biblioteca utilizando Cheerio para extraer información de libros y exponerla mediante endpoints REST en formato JSON.

---

## Tecnologías utilizadas

- Node.js
- Express
- Cheerio
- JavaScript ES Modules
